# Hei, Jeg er Henning

Systemingeniør hos Norsk Helsenett SF. Linux Drift og Automasjon.

### Om Meg

Jeg jobber hovedsakelig med drift av Linux Servere. Der automasjon og kompetanse på nye teknologier er sentralt.
Målet er å automatisere bort kjedelige og manuelle oppgaver, samt å strømlinje prosesser.

**Verktøy som jeg jobber daglig:**

-   **Linux** - Operativsystem og arbeidsflate
-   **Ansible** - Konfigurasjonstyring og automasjon
-   **Docker / Podman** - Containerisering
-   **Kubernetes** - Orkestrering av Containere

Arbeidet mitt innebærer nå nylig oppsett av Ansible Automation Platform (AAP) for å kunne utnytte Ansible i stor skala. men fortsatt forsikre stabil drift og sikkerhet.
